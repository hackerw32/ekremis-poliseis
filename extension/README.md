# Extension Chrome — XE.gr → Αγγελίες

Μαζεύει τις αγγελίες σου από το **xe.gr** και τις εξάγει σε **JSON** που το
ανεβάζεις στην εφαρμογή (Αγγελίες → Δεδομένα → Επιλογή αρχείου / Αντικατάσταση).

## Εγκατάσταση (μία φορά)
1. Άνοιξε στον Chrome τη διεύθυνση: `chrome://extensions`
2. Πάνω δεξιά άνοιξε τον **Developer mode** (διακόπτης).
3. Πάτα **Load unpacked** και διάλεξε αυτόν τον φάκελο:
   `C:\Users\George\Desktop\html projects\APPS\ekremis_poliseis\extension`
4. Θα εμφανιστεί το εικονίδιο «XE.gr → Αγγελίες» στη γραμμή.

## Χρήση
1. Συνδέσου στο **xe.gr** και άνοιξε τη σελίδα με τις αγγελίες σου («Τα ακίνητά μου» / My listings).
2. Πάτα το εικονίδιο του extension → **🔍 Μάζεψε αγγελίες από τη σελίδα**.
3. Έλεγξε τη λίστα, πάτα **⬇️ Κατέβασε JSON** (θα κατέβει `aggelies-xe-ΗΗΗΗ-ΜΜ-ΗΗ.json`).
4. Στο dashboard: **Αγγελίες → Δεδομένα → Επιλογή αρχείου** (για προσθήκη) ή **♻️ Αντικατάσταση όλων** (για ενημέρωση).

## Αν δεν βρει αγγελίες
Πάτα **📋 Αντίγραφο όλης της σελίδας** και στείλε μας το κείμενο — θα προσαρμόσουμε τον parser στα ακριβή δεδομένα του xe.gr.

## Σημείωση
Το extension διαβάζει μόνο τη σελίδα που έχεις ανοιχτή στον browser σου (δεν στέλνει τίποτα πουθενά). Δεν συνδέεται απευθείας με το xe.gr από server — αυτό δεν επιτρέπεται τεχνικά.
